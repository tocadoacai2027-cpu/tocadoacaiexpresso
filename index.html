Verificação automática (beta)

consulta uma API antes de confirmar
🔎 O site consulta uma API de pagamentos (ex.: Mercado Pago) para saber se o PIX caiu antes de confirmar o pedido. Cole abaixo o endereço da consulta e o token. Atenção: em site estático o token fica visível no código da página — para produção completa, use um provedor com proxy. Enquanto isso, o modo manual pede que o cliente confirme e a conferência vai junto na mensagem do pedido.
🖨️

Robô de impressão

Elgin i9 / similar — imprime o pedido no balcão
📌 Toda mensagem de pedido do site começa com NOVO PEDIDO na 1ª linha. No robô de impressão (código Baileys), configure PALAVRA_CHAVE = 'NOVO PEDIDO' para imprimir automaticamente toda mensagem do WhatsApp que contiver essa palavra. Ir para o ar

3 passos e as mudanças vão para o site
1️⃣ Revise as abas (Loja, Menu, PIX & Robô).
2️⃣ Toque em Baixar site atualizado — sai um arquivo toca-do-acai.html com tudo que você editou.
3️⃣ Envie/suba esse arquivo no mesmo lugar onde o site está hospedado (substituindo o antigo). Pronto: as mudanças estão no ar 🎉
🔒

Segurança do admin

quem é cliente não vê nada disso
O acesso do administrador é por senha e fica escondido dos clientes (sem link no site — entre pelo endereço .../toca-do-acai.html#admin ou com 5 toques no logo). É uma proteção básica do próprio arquivo; para senha nível servidor, o ideal é um backend.
